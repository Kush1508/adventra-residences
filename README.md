## ✨ Features & Architecture

- **Velvet Plum Landing Preloader:** First-visit preloader with Roman numeral `XXV`, Spencerian cursive script (`Bihār`, `Heritage`), and arch dive-in transition.
- **Panoramic Day / Night Hero:** Switch between daylight architectural rendering and illuminated evening ambience with interactive pulsing hotspot pins.
- **Powder-Blue Dome Arch & Slideshow:** Grand `rounded-t-[70rem]` dome arch transition into a 3-card curated showcase (*Built to Stay*).
- **Linen Cream Concept & Location Sequence:**
  - Concept narrative with authentic Mediterranean bougainvillea framing
  - New Golden Landmark showcase with sunlit balcony suites
  - Curved coastline/route timeline connecting key landmarks (Gaya Airport, Vishnupad Temple, Mahabodhi Temple)
  - Aerial panorama with drifting cloud marquee animations
- **GSAP-Powered Horizontal Portfolio Flow:** Smooth left-to-right project showcase pinned during scroll with zero dead space.
- **Interactive Blueprints Modal:** Fullscreen unit catalog with 2D blueprint SVGs and live filtering.
- **Direct Lead Routing:** Integrated WhatsApp VIP concierge (+91 6207282057) and private inquiry dispatch.
